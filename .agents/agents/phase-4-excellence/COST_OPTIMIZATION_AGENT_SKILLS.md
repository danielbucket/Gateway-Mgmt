## Overview

The Cost Optimization Agent analyzes resource utilization, identifies waste, optimizes costs, manages licenses, and provides budget forecasting. This agent enables cost-effective operations while maintaining performance and reliability.

**Key Responsibilities**:
- Resource utilization analysis
- Cost allocation and chargeback
- Waste identification and elimination
- Reserved capacity optimization
- License management
- Cloud cost optimization (if applicable)
- Budget forecasting
- Cost vs. performance trade-offs
