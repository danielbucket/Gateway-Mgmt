## Overview

The Documentation Agent manages architecture documentation, runbooks and procedures, configuration documentation, troubleshooting guides, and a comprehensive knowledge base. This agent ensures that operational knowledge is captured, organized, and easily discoverable.

**Key Responsibilities**:
- Architecture documentation
- Runbook and procedure documentation
- Configuration documentation
- Troubleshooting guides
- FAQ and common issues database
- Decision records (ADRs)
- Video tutorials and training materials
- Knowledge base search and discoverability
