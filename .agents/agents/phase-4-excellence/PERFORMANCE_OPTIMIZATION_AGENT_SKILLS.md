## Overview

The Performance Optimization Agent establishes performance baselines, identifies bottlenecks, optimizes queries and resource allocation, implements caching strategies, and performs load testing and benchmarking. This agent ensures system performance meets user expectations and SLAs.

**Key Responsibilities**:
- Performance baseline establishment
- Bottleneck identification
- Query optimization (database, search)
- Caching strategy implementation
- Resource utilization optimization
- Network optimization
- Memory and CPU tuning
- Load testing and benchmarking
